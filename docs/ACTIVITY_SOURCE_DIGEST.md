## 活动骨架

- 活动主题：“守护钱袋子”金融防骗反诈公益日。
- 活动时间：活动日 10:00-16:00，其中 10:00-12:00 为主舞台集中场，13:00-16:00 为 A/B/C 三板块并行体验。
- 活动规模：120-180 人，包含社区老人 60-80 人、学生 60-100 人。
- 主办/协同：民进贵州省委、贵阳银行、贵州财经大学校团委；指导单位为贵阳市公安局反诈中心。
- 核心结构：上午微课堂和情景剧统一建立认知，下午通过 A 区“防骗驿站”、B 区“青春盾牌”、C 区“真的假的鸭”完成分人群互动。
- 筹备节奏：20 天筹备，分为方案确认、物料制作、人员培训、活动执行和复盘传播。

## 三个活动分区

A 区“防骗驿站”面向社区老人，核心服务是手机安全一对一指导、防骗口诀记忆挑战、银行账户安全咨询。它的视觉和交互需要稳定、温和、可信，避免制造紧张感。

B 区“青春盾牌”面向学生，核心内容是反诈剧本杀、短视频拍摄、知识快问快答。它可以更年轻、更有动作感，适合出现短视频框、手举牌、剧场光、题卡和“同龄人教育同龄人”的表达。

C 区“真的假的鸭”面向全体参与者，核心流程是微信扫码进入小程序，完成 5 道判断/情景选择题，即时反馈，展示等级和答对题数，再凭成绩页盖章和领取礼品。这个区是小程序和吉祥物 IP 的主场。

## 小程序产品启发

- C 区标准流程：扫码进入 -> 微信授权 -> 5 题闯关 -> 每题即时反馈 -> 成绩页 -> 等级/礼品 -> 盖“闯关达人”章。
- 隐私边界：不需要手机号，老人操作困难时由工作人员站在身侧协助，不代替选择答案，不收集敏感信息。
- 反馈文案：每题解析控制在 50-80 字，适合现场快速读完。
- 等级体系：反诈小白（0-2 题）、反诈新手（3 题）、反诈达人（4 题）、反诈守护官（5 题）。
- 失败兜底：小程序崩溃、网络中断或排队超过 10 人时，切换纸质答题卡；产品里也应保留“现场工作人员可人工核销”的设计余地。
- 适老化：老人看不清时由协助员朗读题目，界面需要大字、大按钮、少步骤、少授权。
- 分享运营：PPT 中的小程序规划包含答题闯关、案例库、等级体系、分享裂变，后续可从 C 区现场闯关扩展为常态化题库和战绩海报。

## 题库与内容母题

上午集中场重点覆盖 5 类高发骗局：

- 养老投资诈骗
- 冒充客服退款
- 虚假理财/杀猪盘
- 冒充公检法
- 刷单返利

校园场景重点覆盖 6 类高发骗局：

- 刷单返利
- 校园贷/裸贷威胁
- 游戏交易
- 演唱会门票
- 冒充熟人
- 兼职群

高频反诈判断点：

- `96110` 来电应接听。
- 公检法没有“安全账户”。
- 陌生人要求开启屏幕共享，应立即停止。
- 银行客服不会索要验证码。
- 手机下载 App 优先使用官方应用商店。
- 陌生链接不点击，验证码不给任何人，转账前先停下来核实。

## 情景剧与传播启发

上午情景剧《“安全账户”大骗局》通过冒充公检法诈骗呈现“权威恐吓、保密施压、安全账户、紧急转账”的完整链路。对设计和产品而言，最重要的不是表现恐怖场景，而是把“骗子信号”拆成可识别、可点击、可复述的标签。

B 区短视频脚本强调第一眼冲击力和口号化表达，例如兼职先交钱、验证码保护、票务官方渠道、屏幕共享风险等。后续视觉可以把鸭子做成“短视频拍摄指导员”“题卡主持鸭”“剧本杀旁白鸭”等更年轻的活动角色。

预算表列出了实际会制作或租用的物料，设计稿需要考虑低成本、易印刷、远距离可读：

## 预算与执行边界

- 单场总预算：10975 元。
- 必要投入：8905 元。
- 可选投入：2070 元。
- 成本优化方向：批量采购、向学校借用设备、高校志愿者替代部分执行岗位、删减摄影/额外礼品/升级设备。

设计上要优先考虑可复用、可低成本印刷的资产。复杂渐变、过多细节、难以在扇子/钥匙扣/纸巾盒上印清楚的符号，应谨慎使用。

## 安全与隐私原则

- 工作人员不得代输密码、不得目视记录密码、不得询问密码内容。
- A1 手机指导桌面应有“请勿代输密码”提示牌。
- 不拍摄老人手机屏幕。
- 学生短视频拍摄需征得本人同意。
- 小程序不收集手机号。
- 活动全程不收取任何费用，遇到收费说法立即制止并报告项目总控。

这些原则应反映到小程序提示、现场海报、志愿者手卡和主持应急话术中。

## 对视觉方向的进一步判断

- “真的假的鸭”不只是一个胸章鸭图标，更适合发展为活动现场的“闯关主持人”和“防骗陪伴员”。
- 民进元素应继续隐晦表达为教育、文化、公益服务、书页光芒、同心弧线和柔和红金，不应抢占主角。
- 反诈元素可以从“盾牌/对勾”扩展到转账暂停令、任务卡、印章、题卡、证据袋、手机安全门诊、银行柜台、短视频框、口诀扇。
- 视觉要同时照顾老人和学生：老人侧重温和可信、步骤明确；学生侧重互动、短视频、剧场感和挑战感。
- 后续比继续生成单张 logo 更有价值的方向，是做一组“活动落地物料样机”：主背景板、C 区扫码海报、任务卡、成绩页、印章、扇子和手举牌。
