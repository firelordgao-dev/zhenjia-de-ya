# 活动物料视觉系统清单

更新日期：2026-06-07

本文档把“守护钱袋子”金融防骗反诈公益日相关物料整理成一套可执行的视觉系统。目标不是继续做单张 logo，而是让主会场、A/B/C 三个分区、小程序闯关、志愿者执行和礼品传播都能共享同一个公益 IP 语言。

## 总体视觉原则

- 主角是无帽呆毛小鸭，定位为“防骗陪伴员 / 闯关主持人”，不是机构徽章。
- 民进相关气质只用书页光芒、教育文化、公益服务、同心弧线、柔和红金隐晦表达。
- 颜色以暖米白、鸭黄、珊瑚红、柔金、薄荷绿、暖天蓝为主，避免强蓝强红和压迫感。
- 现场远距离物料优先大标题、大图形、少文字；桌面物料优先可操作、可核销、可复述。
- 不使用警察帽、侦探帽、放大镜、恐怖诈骗画面、麦穗/月桂、官方会徽、水印和机构名作为主视觉元素。
- 生成概念图里的中文小字和二维码只作为方向参考，最终印刷稿必须重新本地排版和替换真实二维码。

## 核心叙事

活动总叙事是“先停一下，再识别真假，最后把正确做法带回家”。

- 上午主会场：建立共同认知，突出“守护钱袋子”和五类高发骗局。
- A 区防骗驿站：老人手机安全、银行咨询、口诀记忆，视觉要稳、暖、可信。
- B 区青春盾牌：学生剧本杀、短视频、快问快答，视觉可以更年轻、有动作感。
- C 区真的假的鸭：扫码进入小程序，5 题闯关，成绩页盖章领奖，是 IP 主场。
- 传播礼品：把短口令带走，比如“停一下”“验证码不给”“96110 要接”。

## 分区设计语言

### 主会场

主会场需要最稳、最完整。画面不宜像政府会议背景，也不宜过度儿童化。建议用“书页光芒 + 社区校园广场 + 小鸭主持 + 钱袋守护”组合，正中标题为“守护钱袋子”，副标题承接“金融防骗反诈公益日”。三分区用小图标预告：驿站、盾牌、闯关。

### A 区防骗驿站

A 区围绕老人服务，建议使用手机安全门诊、银行咨询桌、口诀卡、志愿者陪伴等元素。字体要大，步骤要少，文案应像提醒而不是警告。核心短句可用：

- 手机有疑问，先停一下。
- 验证码不给任何人。
- 96110 来电要接听。
- 不让工作人员代输密码。

### B 区青春盾牌

B 区面向学生，可以用剧场灯、短视频框、题卡、手举牌、真/假按钮和校园背景。节奏可以更活泼，但仍避免恐怖骗局画面。核心短句可用：

- 兼职先交钱，多半有问题。
- 演出票务走官方渠道。
- 游戏交易别脱离平台。
- 屏幕共享立刻停。

### C 区真的假的鸭

C 区已经形成 `landing-kit` 方向。后续生产稿应把扫码、5 题、即时反馈、等级、盖章领奖做成同一套视觉，不再拆成孤立图标。现场兜底要保留纸质任务卡和人工核销。

### 执行与安全提示

执行物料要服务志愿者和现场秩序，视觉可以更朴素。重点不是 IP 表情，而是把安全边界说清楚：

- 工作人员不代输密码。
- 不拍摄手机屏幕。
- 不收集手机号。
- 排队超过 10 人可切纸质答题卡。
- 活动不收取任何费用。

## 广告公司交付口径

当前广告公司交付包位于 [output/vendor-package/2026-06-07/](../output/vendor-package/2026-06-07/)。

- `pdf-print/`：核版 PDF，供广告公司替换真实二维码、转曲、转 CMYK、打样和输出。
- `png-preview/`：校对预览图，只用于快速检查，不建议直接印刷。
- `README_VENDOR.md`：文件清单、尺寸、出血、安全区、放大比例和生产注意。
- `production-spec.csv` / `production-spec.md`：广告公司报价、下单、打样和现场分发用规格表，覆盖材质工艺、建议数量、二维码替换、信息替换和打样优先级。
- `handoff/`：活动物料交接手册、分区装箱清单、当天布置清单、供应商验收清单、最终信息回填、印前签核和完成度审计，用于广告公司、执行统筹和 A/B/C 区负责人交接。

交付包不使用 AI 生成图承载正式文字，也不提供 SVG 或可编辑矢量源文件作为主要交付方式，避免字体漂移、错位、覆盖、二维码不可控等问题。正式出街前，广告公司仍需替换真实二维码、转曲、转 CMYK 并打印小样确认。
