# 视觉设计资产索引

更新日期：2026-06-07

本文档记录“真的假的鸭”围绕民进反诈公益、金融反诈公益日、校园/社区活动场景产生的视觉探索资产。这里的图片均为概念方向稿，不等同于最终品牌定稿。

## 当前设计约束

- 主要受众包括社区老人、大学生、银行工作人员、网安/反诈讲演人员、志愿者和活动执行人员。
- 活动语境是“守护钱袋子”金融防骗反诈公益日，包含进社区和进校园两类场景。
- 单张图只保留一个清楚的核心隐喻，不在一张图里重复堆叠同类符号，避免视觉疲劳。
- 吉祥物和胸前标识不写“中国民主促进会”或“民进”，避免误用官方会徽或制造官方标志感。
- 民进相关气质用教育、文化、公益服务、书页、光芒、同心弧线、柔和红金等方式隐晦表达。
- 色彩应比早期强蓝强红版本更柔和、更温暖，降低冷感和压迫感。
- 避免仪式化底座、麦穗/月桂、直接复制官方徽章、警察/侦探造型、放大镜、恐怖诈骗场景、海报式文字堆叠和水印。

- 优先把鸭子做成活动现场的“闯关主持人”和“防骗陪伴员”，不只做单枚 logo。
- 后续视觉资产应能延展到主背景板、扫码海报、任务卡、印章、扇子、手举牌、钥匙扣和小程序成绩页。
- C 区小程序视觉要服务“5 题闯关、即时反馈、等级成绩、盖章领奖”的现场流程。
- 面向老人时要更温和、更清晰；面向学生时可以更有剧场感、短视频感和挑战感。
